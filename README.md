# NFLARG · El Promiedos de la NFL

**https://nflarg.com.ar** — Resultados en vivo, posiciones, estadísticas, planteles y foro de la NFL, NCAA (FBS/FCS), UFL y CFL, con horarios de Argentina y dónde ver cada partido.

- Todo el sitio es un único archivo: [`index.html`](index.html) (HTML + CSS + JS, sin build).
- Datos: API pública no oficial de ESPN. Foro: Supabase ([`supabase/foro.sql`](supabase/foro.sql)).
- Publicado con GitHub Pages desde la rama `claude/nifty-hopper-jra203`.
